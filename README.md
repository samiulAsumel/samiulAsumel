## Three systems in daily use

These run in the Traffic Department, Revenue Branch. Their source repositories are private, and no real port records are published. Each has a case study on the portfolio.

| System | What it does | Links |
|---|---|---|
| **PortBill** | Tiered storage-fee calculator with VAT, levy and mid-period rate changes, for customs and freight-forwarding agents. Output is an estimate, not an official bill. | [Live calculator](https://portbill.pages.dev) · [Case study](https://sasumel.pages.dev/projects/portbill) |
| **CarView** | Offline-first vehicle quantity and location tracker. Replaced a one-person spreadsheet. 8 locations, 7 charts, 13 report sections, Excel export. | [Case study](https://sasumel.pages.dev/projects/carview) |
| **OT Bill** | Overtime bill generator. Employee profile entered once, hourly-rate rule applied, date-wise overtime, A4 print. | [Case study](https://sasumel.pages.dev/projects/otbill) |
